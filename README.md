# ATS Resume Analyzer 🚀

A modern AI-powered ATS Resume Analyzer frontend built using React, Vite and Tailwind CSS.

## Features ✨

- ATS Resume Score
- Resume Upload UI
- Keyword Analysis
- Resume Suggestions
- Formatting Analysis
- Responsive Design
- Dark Mode
- Smooth Animations
- Modern SaaS UI
- Mobile Friendly Layout

## Tech Stack 🛠️

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
